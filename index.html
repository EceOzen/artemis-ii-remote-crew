About This Project
The Mission Log

This is a 10-day live coding series built during the Artemis II mission. Every project uses real NASA open data, published as the mission unfolds — one notebook and one blog post per flight day.

All data comes from publicly available NASA sources: JPL Horizons ephemeris system, NASA Planetary Data System, Lunar Reconnaissance Orbiter imagery, and LOLA elevation data.

Written by Ece Özen İldem — independent researcher, senior software developer, MSc Computational Science & Engineering, climate AI and Earth observation.
